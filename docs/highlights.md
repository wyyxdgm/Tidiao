# AO 特色卖点库（highlights）

> **定位**：面向外叙事的特色功能清单 —— 短视频旁白/发布文案/README 的**卖点词源**。用户视角说话，不放实现细节。
> **维护规则**（damo 2026-10-11 立）：
> 1. **新增大功能上线 = 当轮来本档补一行**（卖点句 + 用户关键词），不许攒。
> 2. 只放「用户会说出口的卖点」；实现真相源在 `docs/usage/` 对应章，本档放指针。
> 3. **检索纪律**：每个卖点必须含用户会搜的**字眼**（fork / 压缩 / 唤回 / 检索…）。新增功能后 grep 本档搜不到该功能的关键词 = 漏了，当场补。
> 关联：`docs/usage/`（功能真相源）/ `docs/strategy/`（对外战略）/ `docs/resume-contract.md`（跨项目唤回机制）/ `docs/claude-config/docs/agent-sdk-standards.md`（fork/checkpoint）
