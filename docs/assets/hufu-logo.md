# 提调 Logo 设计说明

> 品牌：提调（Tidiao）— 平台产品名；虎纹/合符意象保留为功能术语层（dispatch = 授符，verify = 合符）。
> 母版：`docs/assets/hufu-logo.svg`（本目录）；SPA 副本：`spa/public/hufu-logo.svg` + `spa/public/favicon.svg`。

## 意象

对半铜符、锯齿合缝：

- **左半符（蓝 #2a78d6）= 君符**：平台/派发方，授符。
- **右半符（橙 #eb6834）= 将符（虎贲）**：agent/执行方，受符执行。
- **锯齿合缝**：验收 = 合符。两半严丝合缝才能「发兵」，对应任务验收闭环。
- **虎纹**（仅母版大尺寸）：两半同纹，铜符两半刻同一错金铭文的意象。

品牌语义词族：派任务 = 授符，验收 = 合符，agent = 虎贲，一个任务 = 一符。

## 配色（取自现有主题，未造新色板）

| 用途 | Hex | 来源（`spa/src/assets/theme-vars.css`） |
|------|-----|------|
| 君符蓝（主） | `#2a78d6` | `--t-series-1`（light/dark 同值） |
| 将符橙（虎色） | `#eb6834` | `--t-series-2`（light/dark 同值） |
| 虎纹·橙侧 | `#9a3412` | `--tw-orange-800` |
| 虎纹·蓝侧 | `#1e3a8a` | `--tw-blue-900` |

## 深浅背景可用性

四个颜色均为中高饱和实色，白底（`--t-grad-a #f5f7fa`）与深底（`--tw-gray-900 #111827`）下对比度均 ≥ 3:1，无需分深浅两版。透明背景直接用。

## 尺寸规范

| 文件 | 用途 | 最小可辨尺寸 |
|------|------|------------|
| `hufu-logo.svg` | 母版 / 页面展示 / apple-touch 源 | 24px（虎纹 24px 以下消失） |
| `favicon.svg` | 浏览器标签 | 16px（极简版：双半符 + 合缝，已验证） |
| `favicon.ico` | 兼容回退（16/32/48 PNG-in-ICO） | 16px |
| `apple-touch-icon.png` | iOS 主屏（180×180） | — |

## 禁用示例

- ❌ 只用单色改色（换掉蓝/橙 = 破坏「两半合符」语义；单色场景需两半同色不同明度）
- ❌ 拉伸变形（只能等比缩放）
- ❌ 给合缝加描边 / 阴影（合缝留白即视觉主体，加装饰 16px 下糊掉）
- ❌ 旋转（符牌必须水平端正，倾斜 = 剖符不严，合不上）
- ❌ 用在语义相反的场景（如「拆分/失败」图标——提调只表达「合」）

## 生成与维护

- `favicon.ico` / `apple-touch-icon.png` 由 `sharp`（node_modules 传递依赖，非新增）从 `favicon.svg` / `hufu-logo.svg` 导出。改 SVG 后重新导出：参考本仓任一会话内脚本（sharp render + ICO 容器拼接），**无需装新依赖**。
- 若未来可用 `rsvg-convert` / `inkscape`，可直接替换导出命令。
